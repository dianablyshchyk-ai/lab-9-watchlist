# Мій список — starter-проєкт для ЛР №9

Каталог 30 серіалів TVmaze з пошуком, моїм списком і нотатками. HTML, CSS, дані й
модуль стану вже готові. Шар DOM — картки, обробники подій, форми, діалог і
керування фокусом — порожній: його й треба написати в лабораторній роботі.

Опис завдання та специфікація:
<https://denysmatsevych.github.io/web-development-2026/labs/lab-9/> і
<https://denysmatsevych.github.io/web-development-2026/labs/lab-9/task/>.

## Склад

```text
index.html         уся статична розмітка: форма фільтрів, статус, список, шаблон картки, діалог
styles.css         стилі; стан показують атрибути aria-pressed і aria-invalid
data/shows.json    30 серіалів TVmaze
src/state.js       дані й стан (мій список, нотатки) — наданий, не змінюється
src/main.js        точка входу: показує список і підключає модулі нижче
src/render.js      C1 · картки й рядок статусу
src/list.js        C2 · кнопки карток
src/filters.js     C3 · форма фільтрів
src/details.js     C4 · діалог «Детальніше» і форма нотатки
check.html         самоперевірка; її код — у check/
experiments.html   розмітка для експериментів §4
```

Функції в `src/` поки що порожні, тож сторінка відкривається без помилок, але
без жодної картки. Розподіл за файлами — лише пропозиція: структуруйте код як
вважаєте за потрібне, але `src/state.js`, `data/`, `check.html` і `check/` не
змінюйте в жодному коміті.

## Як запустити

Відкрийте `index.html` через **Live Preview** у VS Code (або `npx serve .`) у
Chrome або Edge.
Через `file://` сторінка не запрацює: браузер не завантажує звідти ES-модулі й
JSON (див. ЛР-8, §5.1). `npm install` не потрібен.

## Самоперевірка

Відкрийте `check.html` так само, як `index.html`. Сторінка завантажує застосунок
у фрейм, працює з ним як користувач (клікає, вводить текст, надсилає форми) і
показує кожне правило ТЗ як ✓ або ✗, а внизу — «Пройдено: N з M». Код
застосунку перевірка не читає. Кожна перевірка відкриває свіжу копію
застосунку, тож стан однієї не впливає на іншу.

На початку всі перевірки падають. Повідомлення під ✗ пояснює, що саме не так.
Синтетичні події не довірені, тож справжні Esc, Tab і порядок фокусу перевірка
не бачить: для них є ручний чек-лист у ТЗ.

## Як задеплоїти

Вміст цієї теки можна покласти або в **окремий репозиторій**, або в теку
`lab-9/` спільного репозиторію з лабораторними. Усі шляхи в проєкті відносні,
тому він працює і з кореня сайту, і з підтеки. Самоперевірка — за адресою
сторінки з `check.html` у кінці.

### GitHub Pages

1. Завантажте файли в репозиторій.
2. Settings → Pages → Source: _Deploy from a branch_, гілка `main`, тека `/`.
3. Сторінка з'явиться за адресою `https://<username>.github.io/<repository>/`
   (або `…/<repository>/lab-9/`).

### Vercel

1. [vercel.com](https://vercel.com) → Add New → Project → імпорт репозиторію.
2. Framework Preset: **Other**. Build Command і Output Directory залиште
   порожніми — збирати нічого не потрібно.
3. Якщо проєкт лежить у теці `lab-9/` — **Root Directory → `lab-9`**.
4. Сторінка з'явиться за адресою `https://<project>.vercel.app/`.
